# Task 06: M5 — Финальная приёмка и хардненинг-проверки

**Type:** Verification

## Goal

Прогнать все критерии приёмки проекта (раздел 10 PLAN.md), выполнить security-ревью
кода и финализировать документацию/версию.

## What to Do

- Прогон раздела 10 PLAN.md (10 критериев) с фиксацией результата по каждому пункту.
- Security-ревью (поиском по коду, например через IDE/`grep`):
  - нет `System.out.print*`/`System.err`/`logger.*` рядом с результатом генерации;
  - нет `java.util.Random`, `Math.random`, `currentTimeMillis` в логике генерации;
  - нет внешних URL/CDN в `src/main/resources/web/*` и Java-коде (офлайн);
  - ответы всех API содержат `Cache-Control: no-store` и CSP (по интеграционным тестам).
- Проверка негативных сценариев вручную или тестами: `length=3` → 400, `words=100` → 400,
  все наборы выключены → 400, неизвестный путь → 404, кривой JSON → 400.
- Финализация: версия `1.0.0` в pom (вместо `1.0-SNAPSHOT`), README согласован с фактом,
  опционально git-тег `v1.0.0` (по согласованию с пользователем).
- Обновить PLAN.md: отметить задачу в Task Plan, дополнить Shared Context → Outcomes.

## Files/Areas

- Весь репозиторий — только чтение/проверка; правки только при найденных дефектах
- `pom.xml` — версия 1.0.0
- `PLAN.md` — отметка задачи, outcome

## Key Points

- Это задача-верификация: если критерий не выполняется — фиксируйте дефект и чините
  минимальной правкой (или возвращайте соответствующей задаче, если дефект крупный).
- Приёмка считается завершённой только после явного подтверждения пользователем.
